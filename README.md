# SSTP VPN Server для Ubuntu 24.04

Автоматическая установка и управление SSTP VPN сервером на Ubuntu 24.04 для подключения с Windows 11 (встроенный VPN клиент).

## Быстрая установка

```bash
sudo bash <(curl -s https://raw.githubusercontent.com/potap1978/sstp-server/main/sstp-install.sh)
```

## Возможности

- 🔧 Автоматическая установка всех зависимостей
- 🔐 Генерация SSL сертификатов
- 🌐 Настройка NAT и маршрутизации
- 👥 Управление пользователями (добавление/удаление/смена пароля)
- 🔗 Одноразовые ссылки для скачивания сертификатов
- 📖 Подробная инструкция по подключению Windows 11
- 🖥 Простое меню управления

## Подключение с Windows 11

### Шаг 1 — Получить сертификат
- В меню сервера выберите пункт **6** «Одноразовая ссылка для сертификата»
- Откройте полученную ссылку в браузере на Windows
- Файл `sstp_ca.crt` скачается автоматически

### Шаг 2 — Установить сертификат
1. Двойной клик по файлу `sstp_ca.crt`
2. Нажмите **«Установить сертификат»**
3. Выберите **«Локальный компьютер»** → **Далее**
4. Выберите **«Поместить все сертификаты в следующее хранилище»**
5. Нажмите **«Обзор»** → выберите **«Доверенные корневые центры сертификации»**
6. **ОК** → **Далее** → **Готово**

### Шаг 3 — Создать VPN подключение
1. **Параметры Windows** → **Сеть и Интернет** → **VPN**
2. Нажмите **«Добавить VPN»**
3. Заполните поля:
   - **Поставщик VPN:** Windows (встроенный)
   - **Имя подключения:** SSTP VPN (любое)
   - **Имя или адрес сервера:** (внешний IP вашего сервера)
   - **Тип VPN:** Протокол SSTP
   - **Тип данных для входа:** Имя пользователя и пароль
   - **Имя пользователя:** (логин из пункта 5 меню)
   - **Пароль:** (пароль из пункта 5 меню)
4. Нажмите **«Сохранить»**

### Шаг 4 — Подключиться
- Нажмите на созданное подключение → **«Подключить»**

## Решение частых ошибок

| Ошибка | Решение |
|--------|---------|
| **0x80092013** | Сертификат установлен не в то хранилище. Повторите Шаг 2, выберите «Доверенные корневые центры сертификации» |
| **691** | Неверный логин или пароль. Проверьте пользователей в пункте 4 меню |
| **789** | Неправильный тип VPN. Убедитесь, что выбран именно «Протокол SSTP», а не «Автоматически» |
| **Таймаут** | Порт 443 заблокирован. Проверьте: `ss -tlnp \| grep 443` |

## Полезные команды для сервера

```bash
# Статус сервиса
systemctl status sstp-vpn

# Просмотр логов
journalctl -u sstp-vpn -f

# Перезапуск сервиса
systemctl restart sstp-vpn

# Активные подключения
ip a | grep ppp
```

## Требования

- **ОС:** Ubuntu 24.04
- **Права:** Root доступ (sudo)
- **Порт:** 443 открыт в файрволе
